# Ollama Code Assistant

A local AI-powered coding assistant built with **Ollama (CodeLlama)** and **Gradio**.

## 🚀 Features
- Runs fully offline using Ollama
- Interactive web UI with Gradio
- Supports CodeLlama for coding tasks
- Simple API integration

## 🛠 Tech Stack
- Python
- Ollama
- CodeLlama
- Gradio
- Requests

## 📖 Example Use Cases
- Code generation
- Debugging help
- Algorithm explanations
- Documentation generation

---

Built for learning and experimenting with local LLM-based development tools.
